What it is

macOS has had text-to-speech for decades, and its voices still sound like text-to-speech. MoxSpeak uses Kokoro, an 82-million-parameter open speech model that is small enough to run in real time on a MacBook Air and, to most ears, sounds better than the premium voices Apple ships.

The whole model is inside the app. There is nothing to sign up for, nothing to start, and nothing that stops working on a plane.

Privacy

MoxSpeak asks macOS for Accessibility access so it can read the text you have selected. That is a serious thing to grant a program, so here is exactly what happens with it.

What never leaves your Mac

  • The text you select. Speech is synthesized locally; there is no speech API and no server.
  • Your clipboard.
  • File paths, document titles, window titles, or URLs.
  • Your name, email, or IP address.
  • A list of the apps you use.

What is sent, unless you switch it off

  • Crash reports, so bugs get fixed without anyone having to report them.
  • A short list of usage events: the app launched, speech started and finished, a voice or speed was changed.
  • With those: the app version, your macOS version, and the Mac model generation (for example Mac14,12, which is shared by every unit of that machine).
  • A coarse size band for what was read, such as "under 200 characters". Never the exact length, which would be close to a fingerprint for a particular document.
  • When a read fails, the bundle id of the app it failed in. That is the compatibility backlog in one field. It is never sent when a read succeeds, because a list of apps you used successfully would be a record of what you read and when.

This is not a policy, it is a list in the code. An attribute is sent only if its name is on a fixed allowlist and its value is a short token, and anything else is dropped rather than renamed or truncated. You can read it in TelemetryPayload.swift, and the tests include an attempt to smuggle a sentence out under eight plausible field names, which must fail.

Switch it off under Advanced → Send anonymous usage stats. With it off, the reporting library is never started at all, so nothing is collected or queued for later. Identity is a random identifier made on your machine, not derived from any hardware id, and Reset MoxSpeak clears it.

Questions

Will it run on my Mac?

Apple silicon (M1 or later) and macOS 14 Sonoma or later. Intel Macs cannot run it: the model runs through MLX, which is Apple silicon only.

I installed it and nothing happened.

That is expected. MoxSpeak has no window and no Dock icon; it puts a small diamond in your menu bar. If you cannot see it, check whether a menu bar manager such as Ice, Bartender or Hidden Bar has filed it under hidden items, which is where new icons usually land.

Why does it need Accessibility permission?

It is the only way on macOS to read the text you have selected in another app. Without it MoxSpeak still works, but it reads whatever you last copied instead, so you have to press ⌘C first.

Why is the download 170 MB?

The voice model is inside the app rather than downloaded on first launch. That is what makes it work offline, immediately, with nothing to configure.

How do I uninstall it?

Drag it to the Trash. If you want the settings gone too, choose Advanced → Reset MoxSpeak first, which clears the preferences and the log.

Is it open source?

Source-available. You can read, build, modify and audit it; redistributing it is not permitted. It is public because you should not have to take anyone's word for what an app with Accessibility access does with it.
